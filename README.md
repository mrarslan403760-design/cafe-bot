# CafeBot

A clean, modular web application project for **CafeBot**, an interactive café assistant and ordering platform.

---

## Project Structure

```text
CafeBot/
├── frontend/             # Client-side user interface
│   ├── index.html        # Main HTML markup
│   ├── styles.css        # Visual styling and theme variables
│   └── app.js            # Frontend client scripts and event handling
├── backend/              # Server-side services and API
│   └── server.js         # Backend server entrypoint and route handlers
├── data/                 # Static data and schemas
│   └── menu.json         # Café menu catalog, categories, and pricing
├── prompts/              # AI persona and system prompts
│   └── system_prompt.txt # Prompt definitions for the café conversational assistant
└── README.md             # Project documentation and structure overview
```

---

## Directory Overview

- **`frontend/`**: Contains static web assets including markup (`index.html`), stylesheet (`styles.css`), and JavaScript logic (`app.js`).
- **`backend/`**: Hosts backend services, API endpoints, and business logic (`server.js`).
- **`data/`**: Stores data structures such as café menus, pricing, and item listings (`menu.json`).
- **`prompts/`**: Houses prompt engineering assets and conversational templates for the café bot (`system_prompt.txt`).
